# Исследование котировок акций для обнаружения волатильных паттернов и рыночных трендов

Курсовой проект по дисциплине «Технологии обработки больших данных». **Ченцов Егор, ИД24-3**.

**Статус на 19.10.2026:** постановка задачи, подбор источников и первичное изучение данных. Сведения проверены по коду и сохранённым выводам ноутбука

## Цель и гипотеза

**Цель** - исследовать исторические котировки российских акций и связанные рыночные, макроэкономические и текстовые факторы для классификации ожидаемого направления цены на горизонте **5 торговых дней**

**Гипотеза:** добавление технических, макроэкономических и текстовых признаков улучшает качество классификации тренда относительно модели на исходных котировках. Дополнительный вопрос - какие признаки сильнее связаны с прогнозом; такая связь сама по себе не доказывает причинное влияние

**Объект** - котировки акций и рыночные тренды Московской биржи. Предмет - зависимости между историческими котировками, факторами и будущим направлением цены. В постановке заявлен период с 2022 года. Численные критерии успеха и окончательный состав выборки предстоит закрепить.

## Реализовано

В [основном ноутбуке](Base/Курсовая_Ченцов.ipynb) есть HTTP-загрузка данных, разбор JSON/XML/HTML, объединение котировок со справочником через `pandas.merge` с проверкой `many_to_one`, текстовые признаки и первичный анализ качества.

Сохранённые результаты: **100 строк акций**, **100 строк XML**, **534 строки индексов/iNAV**, **10 текстов Банка России**. Биржевые данные относятся к 01.09.2025, новости — к 09–16.10.2026. Во временную аналитическую выборку они пока не объединены

## Источники — задание 2.2, пункты 3.1–3.4

| Пункт | Источник и реализация | Ограничение |
|---|---|---|
| 3.1. Реляционный набор | [История акций MOEX](https://iss.moex.com/iss/history/engines/stock/markets/shares/securities.json?date=2025-09-01) + [справочник бумаг](https://iss.moex.com/iss/securities.json?engine=stock&market=shares), JOIN по `SECID = secid` | Связанные JSON-таблицы обрабатываются в pandas. Отдельная SQL-база не показана; трактовку требования к реляционному источнику нужно согласовать. |
| 3.2. XML | [История торгов MOEX XML](https://iss.moex.com/iss/history/engines/stock/markets/shares/securities.xml?date=2025-09-01), `document → data → rows → row` | Первая страница за один день; это история акций в другом формате. |
| 3.3. JSON API | [Индексы MOEX ISS](https://iss.moex.com/iss/history/engines/stock/markets/index/securities.json?date=2025-09-01), постраничная загрузка | В ответе также присутствуют расчётные показатели фондов iNAV. |
| 3.4. Неструктурированные данные | [RSS Банка России](https://www.cbr.ru/rss/eventrss) → ссылки → полные тексты HTML-статей | Извлечены 10 текстов, сделана простая разметка; нет векторизации и связи с историческими котировками. |

В каждом обработанном наборе выбраны минимум три категориальных и три числовых поля, есть дата. Для текстов поля вычисляются после извлечения: тема, аудитория, упоминание роста/снижения; количество символов, слов и чисел. Это эвристики, а не оценка влияния новости на акцию. Индексы и сообщения ЦБ рассматриваются как возможные факторы, их связь с целью пока не исследована. [Описание MOEX ISS](https://www.moex.com/a2920).

## Архитектура

**Реализовано:** MOEX JSON/XML и RSS/HTML Банка России → HTTP-запросы → DataFrame → JOIN истории со справочником → преобразование типов, текстовые признаки и проверки качества.

**План:** многолетняя история и факторы за общий период → постоянное хранилище и обновляемый ETL → технические признаки и векторизация → временное разделение train/validation/test → Logistic Regression, Random Forest, Gradient Boosting → сравнение качества и времени → интерактивный дашборд → вывод по гипотезе. Хранилище, обучение, прогнозы и дашборд пока не реализованы.
