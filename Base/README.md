### Характеристики и сохранённые объёмы

| Набор | Категориальные | Числовые | Дата и объём |
|---|---|---|---|
| Акции + справочник | `SECID`, `BOARDID`, `CURRENCYID`, `type` | `OPEN`, `HIGH`, `LOW`, `CLOSE`, `VOLUME`, `VALUE`, `NUMTRADES` | 01.09.2025; 100 строк, справочник 2523 строки |
| XML акций | `SECID`, `BOARDID`, `CURRENCYID` | `OPEN`, `HIGH`, `LOW`, `CLOSE`, `VOLUME` | 01.09.2025; 100 строк |
| Индексы JSON | `SECID`, `BOARDID`, `CURRENCYID` | `OPEN`, `HIGH`, `LOW`, `CLOSE` | 01.09.2025; 534 строки |
| Тексты ЦБ | `topic`, `audience`, `direction` | `characters`, `words`, `numbers` | 09–16.10.2026; 10 статей |

`SECID` — код бумаги/индекса, `BOARDID` — режим торгов, `CURRENCYID` — валюта, `type` — тип бумаги из текущего справочника. OHLC описывает цены/значения индекса; объём, оборот и число сделок — торговую активность. У текстов категории отражают тему, аудиторию и слова о росте/снижении, числовые признаки — длину и упоминания чисел.

### Ограничения

- Акции JSON и XML взяты с первой страницы за один день; XML повторяет тот же предметный набор в другом формате.
- Новости относятся к 2026 году, котировки — к 2025. Как синхронные наблюдения они не объединены.
- Текущий справочник не гарантирует исторически корректных атрибутов бумаги на дату торгов.
- `direction` не является тональностью или влиянием на акцию. При совпадении слов о росте и снижении код выбирает снижение. Качество разметки не оценено.
- Подсчёты слов и символов не заменяют содержательную векторизацию. Проверка «3+3» проверяет число полей, а не их аналитическую полезность.
- Сохранённые 100% пройденных проверок относятся к ограниченному набору проверок и не доказывают полноту данных или готовность курсовой.
